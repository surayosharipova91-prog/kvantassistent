# Kvant Assistant — Квант

**Квант** — голосовой ассистент для Windows с графическим интерфейсом, управлением через микрофон, системным треем и встроенным текстовым чатом.

> Добрый день! Я писал этот проект около трёх недель. Изначально хотел сделать ассистента по мотивам Джарвиса из «Железного человека», но со временем решил превратить его в самостоятельного и удобного голосового помощника. Проект всё ещё развивается, поэтому со временем в нём появляются новые возможности и улучшения.

## Возможности

* 🎙️ **Голосовое управление** — постоянное прослушивание wake-слова с помощью Vosk и распознавание команд через Google Web Speech API.
* 🗣️ **Распознавание русской речи** — поддержка русского языка и команд после обращения «Квант» или других настроенных wake-слов.
* 🖥️ **Управление приложениями** — запуск и закрытие программ, встроенных приложений Windows и ярлыков из меню «Пуск».
* 🎮 **Steam** — запуск игр из библиотеки Steam.
* 🌐 **Работа с сайтами** — открытие сайтов и поиск информации в Google, YouTube и Википедии.
* 🔎 **Поиск в интернете** — выполнение поисковых запросов и получение коротких ответов на вопросы.
* 🎵 **Управление музыкой** — воспроизведение, пауза, следующий трек, регулировка громкости и отключение звука.
* 📸 **Скриншоты** — создание скриншотов с помощью голосовой или текстовой команды.
* 📁 **Файлы и папки** — открытие папок, просмотр содержимого, создание файлов и директорий.
* 💻 **Информация о системе** — просмотр времени, даты, дня недели, загрузки процессора и оперативной памяти.
* ⚡ **Цепочки команд** — выполнение нескольких действий одной фразой.
* ⚙️ **Пользовательские команды** — создание собственных голосовых команд через `config.json`.
* 🎛️ **Пользовательские режимы** — запуск нескольких действий по одной команде.
* 💬 **Текстовый чат** — управление Квантом без микрофона через встроенный интерфейс.
* 🧠 **Локальная LLM** — опциональная интеграция с Ollama для обработки команд.
* 🔊 **Синтез речи** — системный голос Windows через WinRT с резервным использованием SAPI.
* 🎨 **Настраиваемый интерфейс** — цветовая тема, параметры анимации и настройки голоса и распознавания.
* 🔔 **Системный трей** — после закрытия окна Квант может продолжать работать в фоне.

## Как работает распознавание

Квант использует два этапа распознавания речи:

**1. Vosk**

Vosk работает локально и используется для постоянного прослушивания микрофона и обнаружения wake-слова. Благодаря этому не требуется постоянно отправлять весь аудиопоток в интернет.

**2. Google Web Speech API**

После обнаружения обращения к Кванту записанная команда передаётся в Google Web Speech API через библиотеку `SpeechRecognition`, которая выполняет более точную расшифровку произнесённой команды.

Таким образом:

```text
Микрофон
   ↓
Vosk
   ↓
Обнаружение «Квант»
   ↓
Запись команды
   ↓
Google Web Speech API
   ↓
Текстовая команда
   ↓
Обработчик Кванта
   ↓
Действие
```

> ⚠️ Для распознавания самой команды через Google требуется интернет-соединение.

## Интерфейс

Квант имеет собственный графический интерфейс на **PySide6**.

В основном окне доступны:

* история диалога;
* текстовый ввод команд;
* быстрые кнопки;
* визуальный индикатор состояния ассистента;
* индикация активности микрофона;
* настройки интерфейса;
* настройки команд и режимов.

Приложение также может работать через системный трей.

Микрофон можно включать и выключать непосредственно из приложения или сочетанием:

```text
Ctrl + Alt + Z
```

## Примеры команд

```text
Квант, открой Steam
Закрой Discord
Найди на YouTube музыку для работы
Что такое чёрная дыра?
Сделай скриншот
Открой загрузки
Создай файл список покупок в документах
Квант, громкость на 50 процентов
Открой Steam и закрой Discord
```

Команды можно выполнять как по отдельности, так и объединять в одну фразу.

Например:

```text
Открой Steam и закрой Discord
```

Квант последовательно выполнит оба действия.

## Установка и запуск

Проект рассчитан на **Windows**.

Установите Python, откройте PowerShell в папке проекта и выполните:

```bash
py -m pip install -r requirements.txt
```

После установки запустите Квант:

```bash
py -m kvant
```

Для запуска без окна консоли:

```bash
pyw -m kvant
```

При первом запуске убедитесь, что в Windows выбран нужный микрофон и доступны необходимые устройства записи и воспроизведения.

## Сборка лаунчера

Для сборки лаунчера `Квант.exe`:

```bash
py scripts/build_exe.py
```

Лаунчер запускает установленный Python и модуль `kvant` из папки проекта.

> Лаунчер не содержит Python и зависимости приложения. Для работы необходимо, чтобы на компьютере были установлены Python, зависимости из `requirements.txt` и сам проект.

Для запуска Кванта вместе с Windows можно вручную добавить ярлык `Квант.exe` в папку:

```text
shell:startup
```

## Настройка

Основные параметры находятся в:

```text
config.json
```

В конфигурации можно изменить:

* wake-слова;
* голос;
* устройство микрофона;
* пользовательские команды;
* пользовательские режимы;
* пути к программам;
* параметры интерфейса;
* цветовую тему;
* дополнительные параметры распознавания.

### Пользовательские команды

Например:

```json
{
  "phrases": [
    "запусти игру",
    "врубай катку"
  ],
  "action": "steam://rungameid/570",
  "reply": "Запускаю игру."
}
```

Команды также можно создавать и редактировать непосредственно через окно настроек.

### Пользовательские режимы

Режимы позволяют объединять несколько действий и запускать их одной командой.

Например, можно создать режим, который одновременно открывает нужные программы и сайты.

## Голос и синтез речи

Для синтеза речи используются:

* **Windows WinRT** — основной системный механизм;
* **SAPI / pyttsx3** — резервный вариант;
* **XTTS-v2** — опциональный вариант для синтеза речи по аудиореференсу.

Для распознавания речи используются:

* **Vosk** — локальное распознавание для постоянного прослушивания и обнаружения wake-слова;
* **SpeechRecognition + Google Web Speech API** — распознавание самой команды.

## Локальная LLM

При необходимости Квант может использовать локальную языковую модель через **Ollama**.

Она может использоваться как дополнительный механизм обработки команд, которые не удалось определить стандартными правилами.

Это необязательная функция — без Ollama Квант продолжает работать с обычной системой команд.
